# Phillip Duan

Biomedical imaging and research software contributor focused on translating scientific workflows into reliable Python tools.

## Featured work

### [TME-Quant](https://github.com/uw-loci/tme-quant) — Research Software Contributor

TME-Quant is a Python translation of CurveAlign that unifies cell and collagen analysis in a modern Python package and Fiji/napari plugin.

My contributions include:

- Implemented MATLAB-parity image registration and preprocessing workflows for SHG/H&E imagery.
- Built segmentation and ROI-management features, including Fiji/ImageJ interoperability and analysis workflows.
- Developed curvelet-based feature extraction, measurements, visualizations, and batch-processing improvements.
- Strengthened reliability through regression tests, MATLAB golden-reference validation, CI automation, and installation tooling.

**Technologies:** Python, NumPy, SciPy, scikit-image, scikit-learn, SimpleITK, napari, PyQt6, pytest, GitHub Actions
